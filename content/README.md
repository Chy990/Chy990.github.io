# 内容目录

这个文件夹用来放你的个人内容。

- `notes/`：笔记 Markdown 文件。
- `repos/`：仓库/小项目 Markdown 文件。
- `gallery/`：相册图片，支持 `.jpg`、`.jpeg`、`.png`。
- `updates/`：最近更新历史 Markdown 文件。

页面不会再要求你手动维护 `index.json`。

以后新增或删除内容时：

1. 把 `.md` 或图片放进对应目录，或者直接删除不要的文件。
2. 重新双击 `start-blog.command`。
3. 脚本会自动运行 `generate-content-index.py`，刷新页面使用的内容清单。

修改旧笔记时不需要改文件名。保存后重新双击 `start-blog.command`，
脚本会识别正文变化并记录刷新清单的日期；笔记按最近更新或创建日期排列，
卡片和详情仍显示文件名里的创建日期，同时标注「更新于」日期。
生成的 `content-index.js` 和 `content-index.json` 会保存识别变化所需的记录，
发布网站时请连同笔记一起提交。首次启用时只建立记录，不会把已有笔记都标记为更新。

笔记文件名建议使用：

```text
yyyy_mm_dd_type_title.md
```

例如：

```text
2026_06_02_notes_ios2oppo.md
```

## 笔记配图

图片放在和笔记同名的文件夹里（不需要的笔记不用建）：

```text
content/notes/
  2026_11_16_饭后杂谈_体感温度对运动的影响.md
  2026_11_16_饭后杂谈_体感温度对运动的影响/
    温度曲线.jpg
```

在正文里单独占一行插入，路径相对 `content/notes/`：

```md
![当天的温度和风速|wide](2026_11_16_饭后杂谈_体感温度对运动的影响/温度曲线.jpg)
```

- `|` 前面是图片说明，会显示在图片下方，也能被站内搜索到；不写说明就留空：`![](路径)`。
- `|` 后面可选 `wide`、`portrait`、`square`，用来调整图片宽度；不写就是默认宽度。
- 点击图片可以放大查看。
- 笔记图片不生成缩略图，页面直接使用原文件，所以请放压缩过的小图（建议长边 1600px 以内、几百 KB 以内）。
- 图片行不会出现在笔记卡片的预览里，也不计入阅读时长。
- 路径里不要有空格，文件名可以用中文。

## 数学公式

正文支持 TeX 写法，由本地 KaTeX 渲染，不需要连接外部 CDN。

行内公式使用 `$T = 17$`，也可以写成 `\(T = 17\)`。
独立公式使用单独占行的 `$$` 包住内容，不要放在代码块里：

```text
$$
AT = T + 0.33e - 0.70v - 4.00
$$
```

也支持 `\[` 和 `\]` 包住的独立公式，以及单行 `$$...$$`。
多步计算可在公式内用 `\begin{aligned} ... \end{aligned}` 分行。
独立公式不会出现在首页卡片摘要里；手机上过长的公式可以横向滚动。
发布时请一并提交 `vendor/katex-0.19.1/`（含字体及许可证）。
