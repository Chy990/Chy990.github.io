# Minecraft 1.21.11 chy Mod

### GitHub 仓库

[Chy990/minecraft_chy_mod](https://github.com/Chy990/minecraft_chy_mod)

### 简介

这是一个面向 Minecraft Java 1.21.11 的客户端辅助 Mod，通过模拟按键操作实现自动攻击、自动右键和持续潜行，适合挂机刷怪、经验农场和重复放置方块等场景。

当前版本为 v3.3.1，支持 Fabric、Forge 和 NeoForge，需使用 Java 21。只需在客户端安装，服务器无需安装。

### 主要特点

- 自动左键攻击与自动右键交互，左右键间隔可独立设置，默认均为 12 tick。
- 支持持续潜行，可配合自动右键在箱子等方块上放置方块。
- 可开启低饥饿提醒与自动进食：饥饿值降至 14 或以下时，显示时间、饥饿值和血量，并尝试食用副手的金胡萝卜。
- 自动进食期间暂缓自动点击，结束后恢复；退出世界后所有功能重置。
- 输入 `/chy_help` 可查看全部命令与使用说明。
